Plooy — tek sunucu (VPS) production rehberi
=============================================

Yapılandırma: config/env.example  |  Günlük ops: deploy/OPS.txt

Amaç: Site + API + veritabanı + yüklemeler TEK kiralık sunucuda.
Render, Vercel, cPanel runtime'da kullanılmaz.

Mimari
------
  İnternet → nginx (443) → Docker :3001 → Node API + statik React
  Veri     → /opt/sineoda/persistent/data/sineoda.db
  Upload   → /opt/sineoda/persistent/uploads/

Zorunlu .env (/opt/sineoda/.env)
--------------------------------
  PERSIST_DIR=/opt/sineoda/persistent
  JWT_SECRET=<uzun rastgele, deploy sonrası değiştirmeyin>
  FRONTEND_URL=https://plooy.tv
  PUBLIC_URL=https://plooy.tv
  VITE_API_URL=                    (BOŞ — same-origin /api)
  NODE_ENV=production

Deploy (GitHub + VPS)
---------------------
  PC:   npm run check:deploy && git push origin main
  VPS:  cd /opt/sineoda && git pull && bash deploy/rebuild-vps.sh

GitHub'sız: powershell -File deploy/sync-to-vps.ps1

Acil kurtarma: bash deploy/recover-vps.sh

Deploy sonrası doğrulama
------------------------
  curl -s http://127.0.0.1:3001/api/health
  → storage.dbExists: true
  → storage.userCount deploy öncesiyle aynı veya artmış
  → auth.jwtExpiresIn: "30d"

  Tarayıcı: Ctrl+Shift+R — / ve /en açılmalı

Asla yapma
----------
  docker compose down -v
  rm -rf persistent/

Yedek: deploy/backup-vps.sh (her rebuild öncesi otomatik)

İlk kurulum: bash deploy/install-vps.sh
